# Apply-token dialog

## Status: deferred

There is no apply-token comparison dialog in architecture v1. Selecting a ready profile publishes that profile id as one revision-checked, exclusively locked operation.

Selective token adoption depends on a safe override-domain model, which is also deferred. If introduced later, the dialog must operate on a typed plan with explicit before/after values and rollback—not directly mutate CSS or another app's configuration.
