# Icon assets

NL Design does not currently ship a general-purpose icon set.

An earlier build copied 344 icons and six logos from `@amsterdam/design-system-assets`, although no runtime code used them. The package's own asset licence notice excludes those files from the package's open-source licence. To avoid distributing unused assets under a false MPL claim, the dependency, copy script, generated files, and documentation were removed.

This does not prevent a future icon feature. It does require an explicit surface inventory, a supported rendering strategy, provenance, and asset-specific redistribution rights before files enter a release.

The current package candidate also contains no organization-specific profile logos.
The app's EUPL-1.2 code licence would not by itself grant identity or trademark
rights for such assets.
