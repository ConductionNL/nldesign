# Changelog

All notable changes to this project will be documented in this file.

## Unreleased

## 0.2.0-rc2 - 2026-08-08

- Replaced the simple selector UI with a searchable profile library, exact
  version selection, light/dark previews, and installed-version management.
- Added the closed `nldesign-profile-pack/v1` installer. Profile CSS is
  generated by the app and immutable integrity-checked records are stored in
  Nextcloud app data; raw CSS, scripts, URLs, assets, and arbitrary settings are
  rejected.
- Versioned active state, rollback snapshots, history, and stylesheet lookup;
  built-in identities cannot be overwritten and active or rollback-retained
  installed versions cannot be removed.
- Added a public immutable digest-addressed CSS response for installed profiles
  and kept automatic Nextcloud Theming mutation out of the load-bearing path.
- Hardened the Nextcloud 34 administration flow with CSRF headers on reads,
  current toast API detection, named translation placeholders, and labelled
  uninstall controls.
- Added an explicit NC32–34 runtime range gate backed by one shared documented
  CSS-variable contract; equivalent majors no longer carry duplicate adapters.

## 0.2.0-rc1 - 2026-08-08

- Reset the product to a bounded, manifest-backed profile selector with native
  Nextcloud as the default state.
- Added revision-checked, exclusively locked activation, deactivation,
  rollback, and bounded history.
- Added strict profile, package, workflow, dependency, and documentation
  supply-chain gates.
- Isolated private Nextcloud Theming research behind an unregistered
  compatibility boundary; current recommendations remain manual-only.
- Removed package-mutating customization prototypes, unsupported selector
  toggles, obsolete release automation, and unused identity assets.

## 0.1.0 - Initial Release

- Initial app structure
