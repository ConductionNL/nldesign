# Changelog

All notable changes to this project will be documented in this file.

## Unreleased

## 0.2.0-rc1 - 2026-08-08

- Reset the product to a bounded, manifest-backed profile selector with native
  Nextcloud as the default state.
- Added revision-checked, exclusively locked activation, deactivation,
  rollback, and bounded history.
- Added strict profile, package, workflow, dependency, and documentation
  supply-chain gates.
- Isolated private Nextcloud Theming research behind an unregistered
  compatibility boundary; current recommendations remain manual-only.
- Removed package-mutating customization prototypes, unsupported selector
  toggles, obsolete release automation, and unused identity assets.

## 0.1.0 - Initial Release

- Initial app structure
- Basic Nextcloud integration
