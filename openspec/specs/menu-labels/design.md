# App Menu Labels — Retired Design

The former option has no route, control, delegated configuration permission, or
runtime stylesheet. Its structural selector did not match the measured
Nextcloud 33 header and had no packaged evidence across the supported major
range. Hiding menu icons also changes navigation presentation and cannot be
claimed as an accessibility improvement without responsive, keyboard, zoom,
and assistive-technology evidence.

Legacy `show_menu_labels` values are ignored. Any successor belongs in a
separately bounded navigation surface adapter rather than the profile core.
