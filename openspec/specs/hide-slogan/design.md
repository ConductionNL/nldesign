# Hide Slogan — Retired Design

The former option has no route, control, delegated configuration permission, or
runtime stylesheet. Its selector hid Nextcloud's complete guest footer. That
footer contains both the configured instance identity link and the slogan, so
the behavior was broader than the option's name and could not be represented as
a safe slogan-only operation.

Legacy `hide_slogan` values are ignored. Instance slogan changes belong to
Nextcloud Theming. Any future presentation adapter must target a semantically
accurate surface and carry packaged evidence for each supported major.
